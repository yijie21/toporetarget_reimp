toporetarget_reimp

An unofficial reimplementation of TopoRetarget: Interaction-Preserving Retargeting for Dexterous Manipulation, evaluated on ContactPose with the Wuji Hand.

Interactive viewer → Scrub the optimisation, toggle each loss term, compare the human and robot hands side by side. How the method works → Walkthrough of the four stages, from bone directions to the interaction mesh. Stage 3 in detail → Distance-aware weights and Laplacian coordinates, worked through. Source and results → Code, the frozen evaluation protocol, and every number in RESULTS.md.

What the viewer shows

The published demo runs on synthetic grasps. ContactPose and GRAB are licence-gated and their geometry is not redistributed, so payloads for real grasps are generated locally with python scripts/export_viewer.py --source contactpose:mug.

Not affiliated with the paper's authors. No reference implementation was available to check against; the deviations we had to decide for ourselves are listed in the repository's README.
